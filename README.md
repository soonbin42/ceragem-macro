# 세라젬 일괄조작

국립진안고원산림치유원의 세라젬 마스터 V9 여러 대를 **세라젬 IoT 앱에서 차례로 대신 눌러** 켜고, 실행하고, 끄는 안드로이드 앱입니다.

현재 소스 기준은 **v22**입니다. 설치 앱과 GitHub Releases의 버전은 별도로 `1.0.<GitHub Actions 실행 번호>`로 표시됩니다. 변경 내역은 [CHANGELOG.md](CHANGELOG.md)를 확인하세요.

## 설치

1. [최신 릴리스](https://github.com/soonbin42/ceragem-macro/releases/latest)에서 `ceragem-macro.apk`를 폰으로 내려받아 설치합니다. 필요한 경우 출처를 알 수 없는 앱 설치를 허용합니다.
2. 설정 → 애플리케이션 → 세라젬 일괄조작 → ⋮ → **제한된 설정 허용**을 선택합니다(해당 항목이 보이는 기기).
3. 설정 → 접근성 → 설치된 앱 → **세라젬 일괄조작**을 켭니다.

Android 8.0(API 26) 이상이 필요하며, 세라젬 IoT 앱이 설치되어 있어야 합니다.

## 사용

- 상단 **끄기 / 켜기 / 실행** 버튼이나 앱 아이콘을 길게 눌러 나오는 바로가기를 사용합니다.
- 기기별 **척추 / 복부** 칸을 눌러 각각 선택·해제합니다. 번호를 누르면 두 항목을 함께 선택·해제합니다.
- **전체 선택 / 전체 해제**로 선택을 한꺼번에 바꿀 수 있습니다.
- **모드 변경**은 저속 → 정속 → 고속 순으로 다음 실행에 적용할 속도를 고릅니다. 아래쪽 **안정 / 보통 / 빠름**은 자동 조작의 진행 속도 설정입니다.
- 선택 변경 시 보라색 점과 **수정 사항 적용**의 기기 수를 확인하고 적용합니다.
- **점검**으로 세라젬 앱의 상태와 비교합니다. 차이가 있는 기기는 빨간 테두리로 표시됩니다.
- 실행 중에는 폰을 만지지 마세요. **볼륨 아래 버튼 두 번 = 중지**입니다.

기기 칸의 색은 마지막으로 읽은 상태(꺼짐 / 켜짐 / 실행)를 나타냅니다. 실제 상태를 다시 확인하려면 점검을 실행하세요.

## v22 화면 구성

짧은 화면(A25 등)에서는 경과 시간 카드 아래의 마지막 결과 한 줄과 **최근 결과** 등 상세 영역을 첫 화면 밖으로 배치합니다. 아래로 스크롤하면 최근 결과, 속도, 설정, 접근성, 실패 기록, 화면 분석을 볼 수 있습니다. 긴 화면은 기존 배치를 유지합니다. 실제 배치는 기기 수·글자 크기·화면 크기에 따라 확인이 필요합니다.

## 기록과 문제 확인

- **진행 기록 공유**: 최근 실행의 진행 기록을 공유합니다. 문제가 발생하면 `ceragem_report_*.txt` 리포트도 저장합니다.
- **실패 기록 공유**: 실패·확인 안 됨·앱 재실행·네트워크 알림이 있었던 실행의 기록을 기기별·원인별 집계와 함께 공유합니다. 앱 내부에 최대 약 300KB를 보관하며 오래된 실행부터 정리합니다. **기록 지우기**로 삭제할 수 있습니다.
- **10초 뒤 화면 분석**: 누른 뒤 세라젬 앱의 확인할 화면을 띄워 두면 화면 구조를 `ceragem_dump_*.txt`로 저장합니다. **분석 결과 공유**로 전달할 수 있습니다.

Android 10 이상에서는 리포트·분석 파일을 Download 폴더에 저장하고, Android 8~9에서는 앱 전용 외부 저장소에 저장합니다. 저장 실패 시 파일이 없을 수 있으므로 앱의 공유 버튼도 확인하세요. 자동 진행 기록에는 화면의 텍스트와 버튼 정보가 포함될 수 있으며, 공유는 사용자가 공유 버튼을 눌러 진행합니다.

## 소스 수정과 빌드

실제로 빌드되는 Java 소스는 `app/src/main/java/com/jinanhealing/ceragemmacro/`에 있습니다.

| 경로 | 역할 |
| --- | --- |
| `app/src/main/java/com/jinanhealing/ceragemmacro/Config.java` | 설정·선택·기기 상태 저장 |
| `app/src/main/java/com/jinanhealing/ceragemmacro/MacroService.java` | 접근성 자동 조작·점검·진단 |
| `app/src/main/java/com/jinanhealing/ceragemmacro/MainActivity.java` | 앱 화면·선택·실행 버튼 |
| `app/src/main/java/com/jinanhealing/ceragemmacro/FailHistory.java` | 실패 기록 저장·집계 |
| 저장소 최상위의 Java 파일 3개 | 위 실제 빌드 소스의 배포용 사본. 수정 시 같은 내용으로 동기화 |

부분 업데이트 ZIP의 파일은 안내된 실제 빌드 경로에 올리고, 최상위 사본도 함께 갱신하세요. `FailHistory.java`, AndroidManifest, 리소스, Gradle 설정은 프로젝트의 나머지 구성 파일이므로 유지해야 합니다.

로컬 빌드는 JDK 17, Gradle 8.7, Android SDK 34 환경에서 `gradle assembleDebug`로 실행합니다. `main`에 반영하면 GitHub Actions가 APK를 빌드하고 성공 시 새 릴리스를 만듭니다. 기존 앱을 업데이트할 수 있도록 서명 설정과 키를 유지합니다.

## 설치 후 확인

1. A25 등 짧은 화면에서 시간 카드 아래 영역이 스크롤로 보이는지 확인합니다.
2. 긴 화면에서도 기기 칸과 버튼이 잘리지 않는지 확인합니다.
3. 척추·복부 선택, 번호로 함께 선택, 수정 사항 적용, 점검 결과를 확인합니다.
4. 실제 기기를 확인할 수 있는 환경에서 켜기·실행·끄기와 볼륨 아래 두 번 중지를 확인합니다.
5. 최근 결과·실패 기록·화면 분석의 공유 기능을 확인합니다.

빌드 성공은 실제 휴대폰과 세라젬 기기의 동작 검증을 대신하지 않습니다.
