# 세라젬 일괄조작

국립진안고원산림치유원의 세라젬 마스터 V9 여러 대를 **세라젬 IoT 앱에서 차례로 대신 눌러** 한 번에 켜고 / 작동시키고 / 끄는 안드로이드 앱입니다.

## 설치
1. 저장소의 **Releases → 최신 빌드**에서 `ceragem-macro.apk` 를 폰으로 내려받아 설치 (출처를 알 수 없는 앱 설치 허용)
2. 설정 → 애플리케이션 → 세라젬 일괄조작 → ⋮ → **제한된 설정 허용**
3. 설정 → 접근성 → 설치된 앱 → **세라젬 일괄조작** 켜기

## 사용
- 앱의 **전체 켜기 / 전체 실행 / 전체 끄기** 버튼, 또는 앱 아이콘을 길게 눌러 나오는 바로가기
- 실행 중에는 폰을 만지지 말 것. **볼륨 아래 버튼 두 번 = 중지**
- 대상 기기 체크박스로 일부 기기만 선택 가능
- 이미 켜진 기기는 켜기에서, 이미 꺼진 기기는 끄기에서, 이미 작동 중인 기기는 실행에서 건너뜀

## 동작 방식
기기마다 세라젬 앱을 새로 열고 → 목록이 뜰 때까지 기다리고 → 필요하면 스크롤해서 `MASTER V9 0X` 카드를 찾고 → 카드 상태(전원 꺼짐 여부) 확인 → 기기 화면에서 전원 버튼(`do_control_action`) 또는 설정한 모드로 넘긴 뒤 ▶ 를 누릅니다. 실패하면 한 번 다시 시도합니다.

## 문제가 생기면
앱의 **10초 뒤 화면 분석** 버튼을 누르고 세라젬 앱 화면을 띄우면, 화면 구조가 `Download/ceragem_dump_*.txt` 로 저장됩니다. 이 파일을 보내면 버튼 ID 등을 정확히 맞출 수 있습니다.
